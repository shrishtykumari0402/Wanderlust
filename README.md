# Wanderlust – Travel Listing Platform

Wanderlust is an Airbnb-inspired full-stack travel listing platform where users can explore, create, update, and manage property listings. The application provides secure authentication, reviews, image uploads, and location-based services.

## Features

- User authentication and authorization using Passport.js
- Create, edit, and delete property listings
- Add and manage reviews for listings
- Secure CRUD operations for users
- Image upload and storage using Cloudinary
- Interactive maps and location services using Mapbox
- Session management with MongoDB Atlas
- Responsive UI using Bootstrap and EJS templates
